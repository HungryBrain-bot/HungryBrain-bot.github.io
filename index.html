I'm a detection engineer who builds things — not just someone who monitors dashboards. At CyberProof, I operate Microsoft Sentinel and Splunk for enterprise clients across 10+ environments, writing detection rules, investigating alerts, and tuning signal quality every day.

But the work I'm most proud of sits at the boundary between security and AI. I built OpsMind — a production-grade agentic security assistant with real guardrails: canary secret detection, scoped tool access, context isolation, and defences mapped to OWASP LLM Top 10. And detection_As_Code — a CI/CD pipeline that takes detection engineering seriously, with schema-validated deployment, automated testing, and per-customer MITRE ATT&CK Navigator layers.

I think about security as a software engineering problem. When Sentinel's 512-rule hard limit was eating up slots with keep-alive monitoring, I rebuilt the entire monitoring function outside Sentinel using Python and Azure APIs — freeing 30–50 rule slots per customer for actual detection content.

Things I've built
01
detection_As_Code
A production CI/CD pipeline for multi-SIEM detection engineering covering Microsoft Sentinel (KQL), Splunk (SPL), and Google SecOps (YARA-L). Rules are validated against per-customer schemas before deployment — if required telemetry isn't present, the rule is gated. Test harness runs KQL against a Kusto emulator and SPL against a Splunk Enterprise container. MITRE ATT&CK and ATLAS Navigator coverage layers generated per customer.
→ Detection content spans endpoint, Entra ID identity, and LLM application threat domains
KQL SPL YARA-L Python CI/CD MITRE ATT&CK Docker
02
OpsMind
A production-grade agentic security assistant built on Claude APIs. Multi-tool orchestration, stateful reasoning, and MCP server integration. Implements first-principles AI guardrails: canary secret injection to detect data exfiltration, scoped tool access to enforce least-privilege on AI agents, and context isolation to prevent cross-session data leakage. Defences mapped to OWASP LLM Top 10 and MITRE ATLAS.
→ Covers prompt injection, indirect prompt injection, and insecure agentic tool-use as first-class concerns
Claude APIs MCP Python OWASP LLM Top 10 MITRE ATLAS
